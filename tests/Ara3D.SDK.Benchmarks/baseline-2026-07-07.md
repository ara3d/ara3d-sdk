# Plato Geometry Library — Performance Baseline (2026-07-07)

**Pre-optimizer baseline** for roadmap Phase 0.5 (`docs/plato-roadmap.md`, P0.5).
These numbers pin the performance of the current `Plato.Generated` + `Plato.Intrinsics`
code *before* any V2 emitter or optimizer work (P2/P3). All future differential
perf comparisons should be made against this table.

- **Code state:** studio @ `c4fd81f` ("Bump Plato submodule for GitHub Pages demo site."),
  ara3d-sdk nested repo @ `0a0f619`. `Plato.Generated` unmodified.
- **Machine:** Intel Core Ultra 7 155H, 64 GB RAM, Windows 11 Home (10.0.26200.8655)
- **Runtime:** .NET 8.0.28, X64 RyuJIT AVX2, Server GC; BenchmarkDotNet v0.14.0
- **Job:** short run (`WarmupCount=1, IterationCount=3`) — error bars are wide by design;
  means are indicative, not publication-grade. `[MemoryDiagnoser]` enabled.
- **Project:** `tests/Ara3D.SDK.Benchmarks` (not wired into `Ara3D.SDK.sln`).

## What each benchmark measures

- **ArithmeticChain_10k** — `(a+b)*0.5f`, `Dot`, `Cross`, `Normalize` over 10,000 `Vector3`,
  summed. All intrinsic (System.Numerics-backed): ~5.4 ns/vector, zero allocation.
- **Abs_10k / Clamp_10k** — `v.Abs`, `v.Clamp(lo, hi)` over 10,000 `Vector3`. These are
  intrinsics in `Plato.Intrinsics/Vector3.cs` (SNVector3.Abs/Clamp): ~0.7–1.0 ns/vector,
  zero allocation. They are the "after" target for the generated component-wise ops.
- **Lerp_10k** — `v.Lerp(w, t)` over 10,000 `Vector3`. Goes through the *generated*
  `ZipComponents(b, lambda)` path (`_Vector3.g.cs:166`): **~72 ns/vector and 304 B/vector**
  (~100x slower than the intrinsic ops, 3.04 MB per 10k batch).
- **ClampZeroOne_MapComponents_10k** — `v.ClampZeroOne` over 10,000 `Vector3`. The generated
  `MapComponents(lambda)` path (`Components.Map(f)` + `CreateFromComponents`):
  **~72 ns/vector and 168 B/vector**. This is exactly the machinery P3's optimizer targets.
- **CircleToPolyLine2D_1000** — `new Circle(new Point2D(0,0), 1)` → `ToPolyLine2D(1000)`,
  points enumerated to force the lazy `LinearSpace.Map`. ~16.7 ns/sample, near-zero
  allocation (the lazy list wrapper only; note points are *recomputed* on every enumeration).
- **BoundsInclude_1M** — fold 1,000,000 `Point3D` into `Bounds3D` via `Include`, starting
  from `Bounds3D.Empty`. **~132 ns and 432 B allocated per point** (432 MB total!) —
  `Point3D.Min/Max` route through the generated component machinery. Headline optimizer target.
- **Deform_LazyCall / Deform_Evaluated** — `PlatonicSolids.Cube` (`QuadMesh3D`, 8 points)
  `.Deform(p => p + new Vector3(0.1f, 0, 0))`. `Deform` maps lazily, so the call itself is
  ~25 ns / 128 B (closure + mapped-list wrapper); forcing the 8 points costs ~79 ns total.
