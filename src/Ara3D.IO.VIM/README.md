# Ara3D.IO.VIM

Library for reading and writing VIM files. VIM is a binary format designed for efficient
serialization of large-scale BIM models. BIM stands for Building Information Modeling.

Part of the [Ara3D.SDK](https://www.nuget.org/packages/Ara3D.SDK) meta-package.

For more information see: <https://github.com/vimaec/vim-format>.
